## 可搜索 PDF

每页保留原始扫描图（字节未改动），上面叠了一层透明的 OCR 文字，可以直接 Ctrl+F 搜索、复制文字。

- OCR 引擎：RapidOCR（PaddleOCR 模型，ONNX 版）。在样张上对比过 tesseract `chi_sim`，RapidOCR 的中文、英文术语和公式识别都明显更好。
- 文字层脚本：`ocr_pdf.py`（RapidOCR + PyMuPDF）。

## 全文.txt

全书 OCR 文本，每页前面有 `===== 第 N 页 =====` 标记（N 为 PDF 页码 1–562），方便 grep 定位：

```bash
grep -n "Benders" 全文.txt
```

注意：
- **页码偏移**：PDF 页码 ≠ 书上印的页码，正文部分 PDF 页码大约比印刷页码多 36（例如 PDF 第 278 页印的是 242）。
- **OCR 精度**：正文准确率高；公式被压成一行，下标会丢失（如 `x₁` 变成 `x1`），偶有错字；代码缩进不保留。涉及公式、代码、图表时请以原图为准。
