# 02 单智能体 A*

MAPF 的所有主流算法都把“单智能体最短路”当作基础积木，所以先把 A* 吃透。

## 2.1 思路

维护 OPEN 列表，每次取出 *f(n) = g(n) + h(n)* 最小的节点：

- *g(n)*：起点到 n 的已知代价；
- *h(n)*：n 到终点的估计代价。

若 h 是**可采纳**的（永不高估）且**一致**的，A* 第一次取出终点时得到最短路，并且每个节点至多被展开一次。

栅格四连通下常用曼哈顿距离作 h。

## 2.2 代码

`mapf/astar.py: astar`——约 25 行。关键点：

1. 堆里放 `(f, g, node)`，用 `closed` 集合跳过重复弹出；
2. 用 `parent` 字典回溯路径；
3. 仅在找到更小的 g 时才更新并入堆。

运行 `python3 examples/01_astar.py`。

## 2.3 更好的启发函数：真实距离表

`Grid.bfs_distances(goal)` 从终点反向 BFS，得到每格到终点的**精确**最短距离。在有障碍的迷宫中它比曼哈顿距离强得多（曼哈顿会被墙误导）。此后的时空 A* 与 CBS 都复用它，并且每个智能体只需算一次。

## 2.4 练习

1. 在 `maps/maze-10x10.map` 上统计 A* 使用曼哈顿 vs BFS 距离表时展开的节点数。
2. 把 h 乘以 2（不可采纳），观察路径是否变长、展开是否变少。

## 小结

A* = 有方向的 Dijkstra。可采纳启发保证最优；精确距离表是 MAPF 中的标准 h。
