10.6小结与 Lab

  1. 交换论证：取相邻的两个作业交换，只有这两个的完工时间变化。若交换对目标不会变差，反复交换就走到规则给出的顺序。ΣC 的变化是 pb − pa（SPT），ΣwC 的变化是 wapb − wbpa（WSPT），EDD 让最大延迟不变大。
  2. 规则只对它对应的目标有保证：用 SPT 的交换去优化带权重的 ΣwC，或者用 EDD 的交换去优化 ΣC，目标会变差。
  3. Moore–Hodgson：按 EDD 加入，超期就移走已选作业里最长的，得到最少的延误作业个数。加上权重（ΣwU）或者改成延误时间之和（ΣT）就是 NP 难了。
  4. 并行机上，列表调度的近似比是 2 − 1/m（证明：最后一个作业开始时所有机器都忙），LPT 是 4/3 − 1/(3m)；两个界都是紧的，本章给出了取等号的实例。排序这一步把最坏情形从差近一倍降到差三分之一。
  5. 允许中断时，P | prmp | Cmax 有最优的绕圈法，Cmax = max(最长作业, 总量/m)，多项式可解；不可中断的 P | | Cmax 是 NP 难的。
  6. P2 | | Cmax 是子集和，有 O(n · 总量) 的伪多项式动态规划（弱 NP 难）；m 是变量的 P | | Cmax 是强 NP 难。
  7. 在项目里，这些规则是有证明的基准，也是在线策略的原型；它们的保证都建立在“作业一开始就全部就位”上，任务陆续到达时要另外分析。
