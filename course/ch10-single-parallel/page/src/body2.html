10.3并行机：列表调度有多差

机器不止一台，最小化 Cmax（让最后一个作业尽快完成）就成了均衡负荷的问题。P2 | | Cmax 已经是 NP 难，没有简单的规则保证最优。退而求其次：一个很快的算法，最坏能比最优差多少？这个“最多差多少倍”叫近似比。

列表调度（第 9 章）：按给定的顺序，把每个作业放到当前完工最早的机器上。它的近似比有一个简洁的证明（Graham，1966）：设最后完工的作业是 l。它开始的时候，所有机器都是忙的（否则会更早放上去），所以此时每台机器的负荷至少是它的开始时刻 Sl，于是 Sl ≤ (总量 − pl)/m。因此

Graham 界Cmax = Sl + pl ≤ 总量/m + (1 − 1/m)pl ≤ (2 − 1/m) · OPT用到 OPT ≥ 总量/m 和 OPT ≥ pl

如果先把作业按加工时间从大到小排（LPT，longest processing time first），再做列表调度，界会好很多：Cmax ≤ (4/3 − 1/(3m)) · OPT（Graham，1969）。这两个界都是紧的：能构造出让它们取等号的实例。

读图

列表调度，m = 4：12 个单位作业把 4 台机器各铺到 3，最后的长作业（长度 4）接在任何一台后面，Cmax = 3 + 4 = 7。最优是让长作业独占一台，12 个单位作业平分给另外 3 台，每台 4，Cmax = 4。比值 7/4 = 1.75 = 2 − 1/4，正好是 Graham 界。拖动 m：比值 (2m−1)/m 随机器数增加，趋向 2。

LPT，m = 4：9 个作业，LPT 得到 15，最优 12，比值 1.25 = 4/3 − 1/12，正好是 LPT 的界。所以 LPT 已经很好，最多差三分之一；列表调度不排序，最坏差近一倍。这个对比说明排序这一步有多值钱。

10.4可中断与弱 NP 难

前面的所有作业都不能中断。允许中断（prmp）之后，同一个作业可以先做一部分，换到别的机器（或过一会儿）再做完，问题就大不一样。

McNaughton 绕圈法（1959）：允许中断时，P | prmp | Cmax 的最优值恰好是下界

可中断的下界Cmax = max( maxj pj, (Σpj)/m )任何排法都不可能更小；绕圈法能达到

做法：把作业排成一行，第 1 台机器装到 C，再换第 2 台，一个作业装不下就断开，剩下的部分从下一台机器的开头继续。同一个作业的两段一段在前一台机器的末尾，一段在后一台的开头，时间不重叠（因为 C ≥ 它的长度）。图 10-3 切到“可中断：绕圈法”看一个例子：3 台机器，作业 9、9、9、3，总量 30，Cmax = 10；不能中断时最优是 12。

这就是复杂度地图里 P | prmp | Cmax 是绿色、P | | Cmax 是橙色或红色的原因：“不能中断”是难点所在。物流里“一个托盘可以拆成两批搬”“一辆车的任务可以换人接着做”对应可中断；托盘不能拆、车不能中途换，就是不可中断。

P2 | | Cmax：弱 NP 难

不可中断时，两台机器上的 Cmax 是子集和问题：把作业分成两堆，让较大的一堆尽量小，也就是找一堆作业的加工时间之和 s 尽量接近总量的一半（不超过）。用一维的动态规划：reach[s] 表示能否凑出 s，逐个作业更新，时间 O(n · 总量)。最优 Cmax = 总量 − 最大的可达 s。

它是伪多项式的：时间与数值的大小（总量）成正比，而不是与它的位数成正比。加工时间是秒、总量几千时，没有问题；数值是毫秒、总量上亿时就慢了。这就是“弱 NP 难”的含义。对比：m 是变量的 P | | Cmax 是强 NP 难的（3-划分），连伪多项式算法也没有（除非 P = NP）。Lab 挑战让你实现这个动态规划，并在 300 个作业上运行。

10.5在项目里的位置

这一章的规则都很简单，价值在于它们是有证明的基准：你的调度系统在简化的情形下，至少应当不比它们差。

你在乎的规则保证
一台提升机，托盘平均等待最短SPT（有权重用 WSPT）最优（没有释放时间）
每个托盘有发运截止时间，最坏的一单别迟太多EDDLmax 最优
尽量多的托盘赶上截止时间Moore–Hodgson准时的个数最多
多台提升机、多辆车，负荷要均衡LPT + 列表调度Cmax 至多是最优的 4/3 − 1/(3m) 倍
可以把一个大任务拆成几批交给不同的车McNaughton 绕圈法Cmax 最优（可中断）

两点提醒。第一，这些保证都假设作业一开始就全部在那里（没有释放时间）。任务陆续到达时，第 9 章的地图里 1 | rj | Lmax、1 | rj | ΣCj 都是强 NP 难，规则只能当作在线策略（每次机器空闲时，从队列里按规则挑一个），没有最优保证；可中断的版本（SRPT、可中断 EDD）反而是多项式的，见第 30 章。第二，交换论证不只是证明规则用的：它还告诉你 MIP 里可以加哪些有效不等式。如果两个相邻作业按规则排反了不会更好，就可以在模型里禁止这种排法，减小搜索空间（第 11 章）。
