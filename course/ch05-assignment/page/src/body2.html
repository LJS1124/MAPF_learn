5.4为什么 LP 自带整数解：全单模

第 1 章说指派的 LP 松弛顶点都是整数，给了两个理由：Birkhoff 的混合直觉，和一句克莱姆法则。这一节把它证明完整，再做一个能自动找反例的检查器，用来判断“加一行”之后还成不成立。

定义与定理

全单模

矩阵 A 全单模：它的每一个方子式（任取 k 行 k 列交叉出来的 k×k 子矩阵）的行列式都是 0、+1 或 −1。

1×1 的方子式就是元素本身，所以全单模矩阵的元素只能是 0 或 ±1。

Hoffman–Kruskal（1956）

若 A 全单模，b 是整数向量，则 {x : Ax ≤ b, x ≥ 0} 的每个顶点都是整数点。等式约束同理。

证明：顶点是某个非奇异方程组 Bx = b′ 的唯一解。克莱姆法则说每个分量是两个行列式之比，分母 det B = ±1，分子是整数，所以分量是整数。

引理

二部图的顶点–边关联矩阵全单模。指派约束矩阵的每一列恰有两个 1，一个在任务行，一个在车行，正是这种矩阵。

证明见下面，只有四步。

引理对方子式的大小 k 归纳：

  1. k = 1：元素是 0 或 1。
  2. k > 1，任取一个 k×k 子矩阵 B。若有一列全是 0，行列式为 0。
  3. 若有一列恰好一个 1，按这一列展开：det B = ± 一个 (k−1)×(k−1) 子式，由归纳假设是 0 或 ±1。
  4. 否则 B 的每一列恰有两个 1。原矩阵每列的两个 1 一个在任务行，一个在车行，所以 B 里也是这样：把 B 里所有任务行相加，等于把所有车行相加（都是全 1 的向量）。行线性相关，det B = 0。∎

这个证明只用了一件事：行可以分成两组，每一列在两组里各有一个 1。这就是“二部”的含义，也是后面所有反例失效的地方。

有了它，第 1、2 章里几件没解释的事都有了出处：

  • LP 值 = 整数最优。求解器在根节点就证明最优，一次分支也不需要（第 1 章的日志）。
  • 价格也是整数。A 的转置同样全单模，代价是整数时，最优价格 u、v 可以取整数。这就是第 2 章和图 5-2 里价格、标签、约化成本全是整数的原因。
  • 单纯形返回的顶点是真实派法。最优派法不唯一时，最优面上的中间点是分数解，只有顶点才是整数，所以第 1 章要求用对偶单纯形。
Birkhoff–von Neumann：混合直觉是它的特例

行和、列和都是 1 的非负方阵（双随机矩阵）可以写成若干置换矩阵的加权平均。用 Hall 定理证明：任意 k 行的支撑至少覆盖 k 列（否则这 k 行的和 k 会挤进不到 k 列，某列的和会超过 1），所以支撑里有一个完美匹配。取它，减去其中最小的元素，矩阵至少多一个零，行和列和变成同一个更小的常数，对它继续做。最多 n² 轮结束。

这正是第 1 章挑战题“把分数解拆成真实派法”的算法，也是 5.5 节里 decompose 做的事。它和全单模是同一个事实的两种说法：顶点是整数，等价于任何可行点都是顶点的凸组合。

读图

基准。3×3 指派的 6 × 9 约束矩阵有 5,004 个方子式，行列式只取 0、+1、−1：3,213 个零，1,011 个 +1，780 个 −1。

共享名额仍是全单模。“V1 和 V2 合计至多 1 个任务”这一行，等于 V1 那一行加 V2 那一行，它把两辆车当成一个整体来限额。一般地，同一侧的车组只要“要么嵌套、要么不相交”（laminar 族），矩阵就仍是全单模：给每一行标上 ± 号，让同一列上被选中的车组行交替出现 −1、+1，再加上任务行的 +1，每列的和总落在 {0, ±1}，这就是 Ghouila-Houri 判据。

冲突对不是。“V1→T1 与 V2→T2 不能同时出现”把两个互不相干的变量绑在一起，这一行不能并进任何一侧。页面找到的反例是一个 3×3 的子式，行列式 ±2：解 Bx = 1 得到 (½, ½, ½)。“同车冲突”（V1→T1 与 V1→T2）则相反，它被 V1 那一行“至多一个任务”蕴含，没有新东西，矩阵仍是全单模。

两个重叠的名额也不是。V1+V2 ≤ 1 与 V2+V3 ≤ 1 共用了 V2，行不能再分成两组。奇圈是另一种失效方式：三辆车两两之间都可以组队，关联矩阵是三角形的，行列式是 2。

不是全单模，不等于 LP 一定出分数解全单模是“对任意整数右端项都保证整数顶点”的充分条件。具体的代价向量下，LP 的最优顶点可能碰巧仍是整数：在默认场景上加“V1+V2 ≤ 1 与 V2+V3 ≤ 1”，LP 值是 ，整数最优是 。你失去的是保证，不是每一次的结果。所以要看的不是“这次碰巧整数”，而是“换一组代价还会不会”。

5.5加一行，整数性就没了：冲突对与奇圈

全单模是个脆的性质。实际派车里最先破坏它的，往往不是复杂的约束，而是一句“这两个派法不能同时出现”。

冲突有很多来源：两条路线会在主巷道会车，两个任务共用一个月台，两辆车同时要占用提升机。第七部分的时空预约表会把它们检出来。在指派模型里，每一个冲突都是一行 xa + xb ≤ 1。

默认场景里，最优派法是 T1←V3、T2←V2、T3←V1、T4←V4、T5←V5，总共 124 s。假设检测到 V1→T3 与 V2→T2 会冲突。这两条边都在最优派法里，所以它被排除了。用图 5-5 看 LP 怎么反应。

冲突对：LP 只管“平均”

默认的这一对，LP 是 128 s，整数最优是 132 s，差 4 s。LP 的解是两个真实派法的一半一半：一半是原来的最优派法（它同时含两条冲突边），一半是避开这两条边的最好派法（132 s）。两条冲突边的 x 各是 ½，和是 ½ + ½ = 1 ≤ 1，约束满足了。约束只限制“平均”，LP 就允许一半时间做冲突的事，另一半时间什么也不做。真实系统里没有“平均的窗口”，只能二选一，这 4 s 就是选择的价格。

只加了一行，为什么分数解只涉及两个派法？指派多面体加上一个半空间，新的顶点只能落在它的边上：两个相邻的顶点（两个真实派法，彼此只差一条交替路或一个环）之间的线段。这也解释了 Lab 里 decompose 每次只找到两个派法。

拉格朗日看这件事。把这一行乘以价格 λ ≥ 0 吸收进目标：两条冲突边的代价各加 λ，再解一个普通指派，最后减去 λ，得到 L(λ)，它是这个带约束问题的下界。拖动图里的滑块：λ = 0 时是原来的 124；λ 涨到 4，两个候选派法（含两条边的 124 + 2λ，和避开它们的 132）扯平，L 到达最高点 128；再涨，L 又掉下去。最高点恰好等于 LP 值，最优的 λ* = 4 s 是这个冲突的价格：每禁止“两条同时出现”一次，系统愿意为此多付大约 4 s。这是第 2 章“价格”的又一次出场，第五部分的拉格朗日松弛就是把这个做法用到大规模问题上。

奇圈：不是二部图

车队（platoon）把几辆车编成一队一起行驶，最简单的队是两两一组。任意两辆车之间都可以组队，所以这个配对问题的图不是二部图：三辆车 A、B、C 两两相连，构成一个三角形（奇圈）。目标是让组队总收益最大，每辆车至多进一个组。三个收益都是 10 时，整数最优是 10（只能成一组），LP 却给出 15：三条边各取 ½，每辆车的总量是 ½ + ½ = 1，约束满足了。

要修复它，靠的是问题自己的结构，换一个更聪明的求解器没有用。Edmonds 证明：对每个奇数大小的点集 S，加上不等式“S 内部的边至多取 (|S| − 1)/2 条”（奇集割，也叫 blossom 不等式），一般图匹配的 LP 就是整数的。这里 S = {A, B, C}，割是 xAB + xBC + xAC ≤ 1。勾选图里的复选框，½ 的解被切掉，LP 值降回整数最优。它是第 4 章“割平面”的一个结构化例子：割不是求解器随手找的，是从奇圈这个结构里读出来的。

三个收益不相等时，分数解也未必出现：当某一个收益比另外两个之和还大，LP 会直接选它。拖动滑块试试，出现分数解的条件是每个收益都小于另外两个之和，这时三条边各取 ½ 的点（总收益是三者之和的一半）胜过任何单独一条边。

整数性什么时候还在，什么时候没了还在：加的行是同一侧“嵌套或不相交”的车组名额；或者行本身被已有的行蕴含。没了：把两条不相干的边绑在一起（冲突对）、名额相互重叠、引入车与车之间的配对（奇圈）。没了以后，回到第 4 章的分支切割，或者用拉格朗日松弛把这一行“挂”在目标里，让剩下的部分仍是一个指派问题。第 29 章把任务分配和路径规划合到一起时，这些冲突约束会大量出现。
