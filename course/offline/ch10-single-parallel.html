10单机与并行机：一条规则为什么就是最优

第 9 章里反复出现 SPT、WSPT、EDD、Moore–Hodgson，它们是“一条规则就得到最优”的例子。这一章逐个证明它们为什么对，用的是同一个工具：交换论证。再看机器多了以后，快速的列表调度离最优最多差多少，以及允许中断能带来什么。

学完本章，你能

  1. 用交换论证证明 SPT、WSPT、EDD 分别是 ΣCj、ΣwjCj、Lmax 的最优规则，并能预言“规则与目标不匹配”时交换会让目标变差。
  2. 手写 Moore–Hodgson，解释为什么“超期就移走最长的”是对的，以及它为什么不能直接推广到带权重的情形。
  3. 说明并行机上列表调度的近似比 2 − 1/m 和 LPT 的 4/3 − 1/(3m)，构造让它们取等号的最坏实例。
  4. 用 McNaughton 绕圈法解可中断的并行机问题，用子集和动态规划解 P2 || Cmax，并理解“弱 NP 难”的意思。

10.1交换论证与三条规则

单机上排 n 个作业有 n! 种顺序，却常常只需要按某个量排一下序。为什么这样是对的？答案是一个很朴素的想法：如果一个顺序里有相邻的两个作业“排反了”，把它们换过来，目标不会变差。一直换下去，就走到规则给出的顺序。

取顺序里相邻的两个作业 a（在前）和 b（在后），它们开始于时刻 t。交换 a 和 b 只改变这两个作业的完工时间，别的作业的完工时间都不受影响（前面的没动，后面的作业开始时刻仍是 t + pa + pb）。

SPT：1 | | ΣCj

交换前两个作业的完工时间是 t + pa 和 t + pa + pb；交换后是 t + pb 和 t + pa + pb。ΣC 的变化 = pb − pa。

若 pa > pb，交换让 ΣC 减少。所以最优顺序里不会有“长的在短的前面”的相邻对，即加工时间从小到大。

WSPT（Smith 规则）：1 | | ΣwjCj

同样的算法，变化 = wapb − wbpa。

它 ≤ 0 当且仅当 pb/wb ≤ pa/wa。所以按 pj/wj 从小到大排（“单位权重的加工时间”越小越先做）。权重全为 1 就是 SPT。

EDD（Jackson 规则）：1 | | Lmax

设 da > db，a 排在前面。交换前，b 的延迟是 Lb = t + pa + pb − db。交换后 b 的延迟更小，a 的延迟 t + pa + pb − da 也小于交换前 b 的延迟（因为 da > db）。

这两个作业的最大延迟不会变大，所以最大延迟不会变大。最优顺序里可以让交货期早的先做。

结论：从任意一个顺序出发，只要还有“排反了”的相邻对，就交换，目标不变差；交换总会结束（每次交换减少逆序对），结束的顺序就是规则给出的顺序。所以规则给出的顺序不比任何一个起点差，也就是最优。这就是交换论证（interchange argument）。证明不需要枚举，只需要看两个相邻的作业。

读图

SPT 观察 ΣC，从 J1…J6 出发：7 次交换，目标 104、100、98、93、90、89、86、84，每次都下降，最后是最优的 84。每一步的降幅正好是公式里的 pa − pb。

切到 WSPT 观察 ΣwjCj：8 次交换，322 一路降到 234，从不变差。切到 EDD 观察 Lmax：目标不变差，16 → 7，中间有不少步保持 16 不变，因为最大延迟由别的作业决定。

再试不匹配的组合。把规则选成 SPT，目标选成 ΣwjCj：交换按“p 小的先”，但目标关心权重。从 J1…J6 出发，第 6 步 252 变成 256，变差了，并且最后停在 252，比最优的 234 高。把规则选成 EDD，目标选成 ΣCj，第 1 步就变差，最后是 108，比 SPT 的 84 差得多。规则只对它对应的目标有保证，这也是第 9 章说“选目标就是选规则”的原因。

10.2Moore–Hodgson：让延误的作业最少

前三条规则都是“排个序”。ΣUj（延误作业个数）不一样：它不在乎晚多少，只在乎晚不晚。既然有的作业注定晚，不如干脆让它们晚到底，把机器的时间让给还有希望的作业。

Moore–Hodgson（1968）的做法：

  1. 按交货期从早到晚（EDD）依次把作业加进“准时集合”。
  2. 每加一个，检查现在的完工时间是否超过这个作业的交货期。
  3. 超了，就从准时集合里移走加工时间最长的一个（可以是刚加进来的）。被移走的作业放弃，排在最后，接受延误。

为什么移最长的？要让剩下的作业尽早完成，就要腾出最多的时间。移走任何一个作业都能让后面的完工时间提早，移走最长的提早得最多，而且被放弃的代价（少一个准时作业）对每个作业都一样，都是 1。这就是“个数”目标的特点：所有作业的价值都是 1，所以要放弃“占地方最大”的那个。

读图

例 1：EDD 顺序是 J4、J5、J1、J3、J6、J2。加入 J4（2），加入 J5，完工时间 10，超过它的交货期 9，超期：在 {J4, J5} 里移走最长的 J5（8），完工时间回到 2。之后 J1、J3、J6、J2 都按期。只延误 J5 一个，是最优的。直接按 EDD 排，延误 5 个。

例 2更紧：7 个作业，EDD 直接排延误 6 个；Moore–Hodgson 依次移走 J3、J2、J7，延误 3 个，仍是最优（枚举核对）。

别推广过头加上权重，1 | | ΣwjUj（最小化延误作业的权重之和）就是背包问题的推广，是弱 NP 难的（第 9 章的地图里是橙色）。“移走最长的”不再对：有时该移走一个短的但权重小的。同样，1 | | ΣTj（延误时间之和）也是 NP 难的。看起来很像的目标，难度可以差得很远。

10.3并行机：列表调度有多差

机器不止一台，最小化 Cmax（让最后一个作业尽快完成）就成了均衡负荷的问题。P2 | | Cmax 已经是 NP 难，没有简单的规则保证最优。退而求其次：一个很快的算法，最坏能比最优差多少？这个“最多差多少倍”叫近似比。

列表调度（第 9 章）：按给定的顺序，把每个作业放到当前完工最早的机器上。它的近似比有一个简洁的证明（Graham，1966）：设最后完工的作业是 l。它开始的时候，所有机器都是忙的（否则会更早放上去），所以此时每台机器的负荷至少是它的开始时刻 Sl，于是 Sl ≤ (总量 − pl)/m。因此

Graham 界Cmax = Sl + pl ≤ 总量/m + (1 − 1/m)pl ≤ (2 − 1/m) · OPT用到 OPT ≥ 总量/m 和 OPT ≥ pl

如果先把作业按加工时间从大到小排（LPT，longest processing time first），再做列表调度，界会好很多：Cmax ≤ (4/3 − 1/(3m)) · OPT（Graham，1969）。这两个界都是紧的：能构造出让它们取等号的实例。

读图

列表调度，m = 4：12 个单位作业把 4 台机器各铺到 3，最后的长作业（长度 4）接在任何一台后面，Cmax = 3 + 4 = 7。最优是让长作业独占一台，12 个单位作业平分给另外 3 台，每台 4，Cmax = 4。比值 7/4 = 1.75 = 2 − 1/4，正好是 Graham 界。拖动 m：比值 (2m−1)/m 随机器数增加，趋向 2。

LPT，m = 4：9 个作业，LPT 得到 15，最优 12，比值 1.25 = 4/3 − 1/12，正好是 LPT 的界。所以 LPT 已经很好，最多差三分之一；列表调度不排序，最坏差近一倍。这个对比说明排序这一步有多值钱。

10.4可中断与弱 NP 难

前面的所有作业都不能中断。允许中断（prmp）之后，同一个作业可以先做一部分，换到别的机器（或过一会儿）再做完，问题就大不一样。

McNaughton 绕圈法（1959）：允许中断时，P | prmp | Cmax 的最优值恰好是下界

可中断的下界Cmax = max( maxj pj, (Σpj)/m )任何排法都不可能更小；绕圈法能达到

做法：把作业排成一行，第 1 台机器装到 C，再换第 2 台，一个作业装不下就断开，剩下的部分从下一台机器的开头继续。同一个作业的两段一段在前一台机器的末尾，一段在后一台的开头，时间不重叠（因为 C ≥ 它的长度）。图 10-3 切到“可中断：绕圈法”看一个例子：3 台机器，作业 9、9、9、3，总量 30，Cmax = 10；不能中断时最优是 12。

这就是复杂度地图里 P | prmp | Cmax 是绿色、P | | Cmax 是橙色或红色的原因：“不能中断”是难点所在。物流里“一个托盘可以拆成两批搬”“一辆车的任务可以换人接着做”对应可中断；托盘不能拆、车不能中途换，就是不可中断。

P2 | | Cmax：弱 NP 难

不可中断时，两台机器上的 Cmax 是子集和问题：把作业分成两堆，让较大的一堆尽量小，也就是找一堆作业的加工时间之和 s 尽量接近总量的一半（不超过）。用一维的动态规划：reach[s] 表示能否凑出 s，逐个作业更新，时间 O(n · 总量)。最优 Cmax = 总量 − 最大的可达 s。

它是伪多项式的：时间与数值的大小（总量）成正比，而不是与它的位数成正比。加工时间是秒、总量几千时，没有问题；数值是毫秒、总量上亿时就慢了。这就是“弱 NP 难”的含义。对比：m 是变量的 P | | Cmax 是强 NP 难的（3-划分），连伪多项式算法也没有（除非 P = NP）。Lab 挑战让你实现这个动态规划，并在 300 个作业上运行。

10.5在项目里的位置

这一章的规则都很简单，价值在于它们是有证明的基准：你的调度系统在简化的情形下，至少应当不比它们差。

你在乎的规则保证
一台提升机，托盘平均等待最短SPT（有权重用 WSPT）最优（没有释放时间）
每个托盘有发运截止时间，最坏的一单别迟太多EDDLmax 最优
尽量多的托盘赶上截止时间Moore–Hodgson准时的个数最多
多台提升机、多辆车，负荷要均衡LPT + 列表调度Cmax 至多是最优的 4/3 − 1/(3m) 倍
可以把一个大任务拆成几批交给不同的车McNaughton 绕圈法Cmax 最优（可中断）

两点提醒。第一，这些保证都假设作业一开始就全部在那里（没有释放时间）。任务陆续到达时，第 9 章的地图里 1 | rj | Lmax、1 | rj | ΣCj 都是强 NP 难，规则只能当作在线策略（每次机器空闲时，从队列里按规则挑一个），没有最优保证；可中断的版本（SRPT、可中断 EDD）反而是多项式的，见第 30 章。第二，交换论证不只是证明规则用的：它还告诉你 MIP 里可以加哪些有效不等式。如果两个相邻作业按规则排反了不会更好，就可以在模型里禁止这种排法，减小搜索空间（第 11 章）。

10.6小结与 Lab

  1. 交换论证：取相邻的两个作业交换，只有这两个的完工时间变化。若交换对目标不会变差，反复交换就走到规则给出的顺序。ΣC 的变化是 pb − pa（SPT），ΣwC 的变化是 wapb − wbpa（WSPT），EDD 让最大延迟不变大。
  2. 规则只对它对应的目标有保证：用 SPT 的交换去优化带权重的 ΣwC，或者用 EDD 的交换去优化 ΣC，目标会变差。
  3. Moore–Hodgson：按 EDD 加入，超期就移走已选作业里最长的，得到最少的延误作业个数。加上权重（ΣwU）或者改成延误时间之和（ΣT）就是 NP 难了。
  4. 并行机上，列表调度的近似比是 2 − 1/m（证明：最后一个作业开始时所有机器都忙），LPT 是 4/3 − 1/(3m)；两个界都是紧的，本章给出了取等号的实例。排序这一步把最坏情形从差近一倍降到差三分之一。
  5. 允许中断时，P | prmp | Cmax 有最优的绕圈法，Cmax = max(最长作业, 总量/m)，多项式可解；不可中断的 P | | Cmax 是 NP 难的。
  6. P2 | | Cmax 是子集和，有 O(n · 总量) 的伪多项式动态规划（弱 NP 难）；m 是变量的 P | | Cmax 是强 NP 难。
  7. 在项目里，这些规则是有证明的基准，也是在线策略的原型；它们的保证都建立在“作业一开始就全部就位”上，任务陆续到达时要另外分析。
