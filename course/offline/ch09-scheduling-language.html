9调度问题的语言：一句话说清是什么问题，有多难

前两部分回答“谁做、怎么走”。这一部分回答“什么时候做”：提升机、站点、堆垛设备都是要排队的机器。调度领域有一套简洁的记号，一个三段式的标签就能说清机器怎么配置、有什么约束、要优化什么。学会读写这个标签，就能在文献里迅速找到你的问题，知道它是容易的还是难的。

学完本章，你能

  1. 用作业、机器、调度、甘特图描述一个排班问题，区分“分配、排序、定时”三类决策。
  2. 读写 α | β | γ 三段式记号，把提升机、多车、站点串联这些场景翻译成标签。
  3. 计算 Cmax、ΣCj、ΣwjCj、Lmax、ΣTj、ΣUj，并解释为什么没有一种排法能让它们同时最好。
  4. 用“特例与推广”的关系推理一个问题的复杂度，读复杂度地图，知道该去用规则、动态规划、还是启发式与求解器。

9.1什么是调度问题

6 个托盘要过同一台提升机。每个托盘占用提升机若干秒，有的着急、有的不急，有的必须赶上某个发运截止时间。谁先上、谁后上？这就是一个调度问题。

调度问题的基本语言只有三样：

作业（job）

要完成的活，编号 j。每个作业有：加工时间 pj（占用机器多久）；释放时间 rj（最早什么时候能开始）；交货期 dj（最好什么时候完成）；权重 wj（有多重要）。

机器（machine）

做活的资源。提升机、堆垛机、装卸月台、四向车，在调度里都可以当作机器：同一时刻只能做一个作业。

调度（schedule）

给每个作业指定在哪台机器上、什么时候开始。画出来是甘特图：横轴是时间，每台机器一行，每个作业是一个方块。作业 j 的完工时间记作 Cj。

做一个调度，其实是做三类决策：分配（每个作业去哪台机器）、排序（同一台机器上先做谁）、定时（每个作业几点开始）。单台机器、没有释放时间的时候，只剩排序：6 个作业有 6! = 720 种顺序。

本章反复用到的例子：一台提升机，6 个托盘。

作业J1J2J3J4J5J6
加工时间 p735285
权重 w224442
交货期 d1323175921

总加工时间 30，所以不管怎么排，最后一个作业都在时刻 30 结束。但每个作业各在什么时候完成，取决于顺序，好坏也就取决于你在乎什么，这就是下一节要回答的问题。

9.2三段式记号

Graham 等人（1979）给调度问题定了一套记号：α | β | γ。三段分别说机器、约束、目标。一句话能说清楚一个问题，也是查文献的关键词。

段含义常见取值
α 机器环境有几台机器，怎么配置1 单机；Pm 相同并行机；Qm 速度不同的并行机；Rm 不相关并行机；Fm 流水车间；Jm 作业车间；Om 开放车间
β 约束与特征作业的附加条件，可以为空或多个rj 有释放时间；prec 先后约束；prmp 允许中断；dj 交货期是硬性的；sjk 准备时间（与顺序有关）
γ 目标要最小化什么Cmax、ΣCj、ΣwjCj、Lmax、ΣTj、ΣUj……

几个例子，读一遍，感受一下：

  • 1 | | ΣCj：一台机器，没有额外约束，让所有作业的完工时间之和最小（平均等待最短）。
  • 1 | rj | Lmax：一台机器，作业陆续到达，让最晚的那个比交货期迟得最少。
  • P2 | | Cmax：两台相同的机器，让最后一个作业尽快完成（均衡负荷）。
  • R | | ΣCj：不相关并行机，每个作业在不同机器上时间不同，让完工时间之和最小。
  • F2 | | Cmax：两台机器串联的流水车间，每个作业先过第一台再过第二台。

后面 9.5 节的图 9-3 让你自己拼一个标签，它会告诉你这个问题在文献里是容易还是困难。

9.3目标函数：你在乎什么

“排得好”没有唯一的意思。同一批作业，追求的东西不同，最优的顺序也不同。常见的目标都由完工时间 Cj 和交货期 dj 算出来：

目标公式在乎什么
最大完工时间（makespan）Cmax = max Cj所有活多久干完，设备利用率
完工时间之和ΣCj　或　ΣwjCj平均等待，在制品库存；权重表示重要程度
最大延迟（lateness）Lmax = max(Cj − dj)最坏的那一单迟了多少；可以是负数（提前）
延误时间之和（tardiness）ΣTj，Tj = max(0, Cj − dj)迟到总共多久，提前不奖励
延误作业个数ΣUj，Uj = 1 若 Cj > dj有几单没赶上截止时间

这些目标都是正则的：完工时间变大，目标不会变好。所以没有必要故意让机器空转，最优调度里作业总是尽早开始。

读图

SPT（最短加工时间优先）：J4、J2、J3、J6、J1、J5。它让 ΣCj 达到 84，这是最优（比先来先做的 104 少了近两成），但 Lmax 是 21，有 2 个作业延误。WSPT（加权最短优先）让 ΣwjCj 最优（234），此时重要的作业排在前面。EDD（最早交货期优先）让 Lmax 最小（7），但 ΣCj 涨到 108，延误作业的个数是 5。Moore–Hodgson 只有一个作业延误（ΣUj = 1，最优），代价是 Lmax 高达 21：它干脆把那个赶不上的作业放到最后。

所以目标函数决定了你该用什么规则。这些规则（SPT、WSPT、EDD、Moore）都是精确的多项式算法，下一章会逐个证明它们为什么对。

把 ΣCj 和 Lmax 放在一起看：它们冲突。所有顺序里，两个目标的帕累托前沿有 8 个点，从 (ΣC = 108, Lmax = 7) 到 (84, 21)，想让最坏的一单迟得少，就得让平均等待变长。到底选哪一个点，是业务的决定，不是算法的决定。

9.4机器环境：有几台，怎么配

机器不止一台的时候，先要分清机器之间是什么关系。

并行机：一个作业只在一台机器上做一次

P（相同）：加工时间与机器无关。Q（速度不同）：机器 i 的速度是 si，时间是 pj / si。R（不相关）：pij 是任意的一张表，机器各有所长，比如不同位置的四向车做同一个任务的行驶时间。

车间：一个作业要依次经过几台机器

F 流水车间：所有作业经过机器的顺序相同（入库 → 提升机 → 出库）。J 作业车间：每个作业有自己的路线。O 开放车间：作业要在每台机器上做，顺序不限。第 11 章展开。

P、Q、R 越往后越一般：P 是 Q 的特例（所有速度为 1），Q 是 R 的特例（pij = pj / si）。这个“特例关系”后面用来推理复杂度。

读图

单机：Cmax = 30，总加工时间，顺序无关。两台相同的机器：总量 30，下界 15。按编号列表调度得到 16，最优是 15；改成“最长的先放”（LPT）就得到 15。列表调度是一种很快的启发式，但它没有保证一定最优，即使是最简单的 P2 || Cmax，它也是一个 NP 难的问题（由划分问题推出）。

两台不相关的机器：按编号列表调度恰好是最优（11）；换成“最长的先放”，得到 14，比最优多 3。顺序策略对不同环境的效果不同，没有哪一条规则永远最好，所以要知道问题是哪一类，才能知道该用哪种方法。

9.5复杂度地图：哪些容易，哪些难

调度领域积累了几百个问题的复杂度结果。你不需要背，只需要理解推理规则：一个问题至少和它的特例一样难，至多和它的推广一样容易。

  1. 特例与推广：1 是 P 的特例，P 是 Q 的特例，Q 是 R 的特例；没有释放时间是有释放时间的特例；Cmax 是 Lmax 的特例（令 dj = 0）；ΣCj 是 ΣwjCj 的特例（令所有 wj = 1）。
  2. 难度沿推广传播：如果 A 是 NP 难的，B 是 A 的推广，B 也是 NP 难的。因为解 B 的算法可以拿来解 A。
  3. 容易沿特例传播：如果 B 有多项式算法，A 是 B 的特例，A 也有。
  4. 但可中断（prmp）不在这个序里：允许中断可能让问题变容易，也可能没有影响，不能靠它推理。

“NP 难”也有强弱：弱 NP 难的问题有伪多项式时间的算法（数值不大时可以用，比如动态规划），强 NP 难的问题连这样的算法也没有（除非 P = NP）。图 9-3 里橙色是弱 NP 难，红色是强 NP 难或没有区分。

读图

先看 β 为空的地图：单机（第一行）上，目标几乎全是多项式可解的：Cmax、ΣCj、ΣwjCj、Lmax、ΣUj 都有简单的规则。往下走，机器变多，绿色越来越少：P2 的 Cmax 已经是 NP 难（划分问题）。同一个机器环境里，目标不同，难度也可以完全不同：R || ΣCj 是多项式的（它就是第 5 章的指派问题），R || Cmax 却是强 NP 难。

再加 β：点亮 rj（释放时间）。单机的 Lmax、ΣCj 立刻变成红色：没有释放时间时 EDD、SPT 一步到位，一旦作业陆续到达，问题就变成强 NP 难。这个变化对系统很重要：任务动态到达，会让原本简单的排序问题变难，也是第 30 章在线调度的出发点。

复杂度地图的用法遇到一个调度问题，先写出它的三段式标签，查地图。绿色：找对应的规则或算法，不要建 MIP。橙色：数值不大时用动态规划。红色：用 MIP 或约束规划（第 11 章）求解小规模，用启发式（第 21 章）求解大规模，并用下界评价解的质量。

9.6在项目里的位置

把你场景里的设备翻译成三段式标签，是这一部分每一章开始前要做的事。

场景记号难度与做法
一台提升机，托盘排队，尽量减少平均等待1 | | ΣCj（或带权重 ΣwjCj）多项式：SPT / WSPT（第 10 章）
一台提升机，托盘要赶发运截止时间1 | | Lmax；1 | | ΣUj多项式：EDD；Moore–Hodgson（第 10 章）
托盘陆续到达提升机（不知道后面会来什么）1 | rj | Lmax强 NP 难；在线时更难（第 30 章）
两台提升机分担同一批托盘P2 | | CmaxNP 难（弱）；LPT 有 7/6 的近似（第 10 章）
多辆四向车，各自到每个任务的时间不同R | | ΣCj多项式：指派问题（第 5 章）
入库 → 提升机 → 出库，三个工位串联F3 | | Cmax强 NP 难；MIP 或启发式（第 11 章）
设备在两个作业之间要移动，移动时间取决于前后两个作业1 | sjk | Cmax就是旅行商问题（第 8 章）
提升机、站点是共享资源，有时间窗超出经典记号，需要资源约束的扩展RCPSP、时间索引 MIP（第 12 章）

其中最后一项提醒：三段式记号覆盖的是经典模型。真实系统里的约束（时间窗、共享资源、设备之间的互斥）往往超出记号，这时它的价值是让你说清“最接近的经典问题是什么”，然后知道自己在它的基础上加了什么、复杂度大致会怎样变化。

9.7小结与 Lab

  1. 调度问题由作业（p、r、d、w）、机器和调度（分配、排序、定时）组成，用甘特图表示。提升机、堆垛机、月台、四向车在调度里都是“机器”。
  2. 三段式记号 α | β | γ 分别是机器环境、约束、目标：1、P、Q、R 是并行机，F、J、O 是车间；β 里常见 rj、prec、prmp、sjk；γ 是要最小化的目标。一个标签能说清一个问题，也是查文献的关键词。
  3. 目标不同，最优的排法不同：ΣCj 偏爱 SPT，ΣwjCj 偏爱 WSPT，Lmax 偏爱 EDD，ΣUj 偏爱 Moore–Hodgson。没有一种排法能让所有目标同时最好；ΣCj 与 Lmax 的帕累托前沿有 8 个点。选目标是业务的决定。
  4. Cmax 在没有释放时间的单机上与顺序无关（总加工时间）；并行机上它是均衡负荷问题，列表调度（LPT 等）是快速的启发式，但不保证最优。
  5. 复杂度靠“特例与推广”推理：问题至少和它的特例一样难，至多和它的推广一样容易；可中断（prmp）不在这个序里。单机上大部分目标有简单的规则，机器一多、加上释放时间，许多问题就变成 NP 难；同一个机器环境里目标不同，难度可以相差悬殊（R || ΣCj 是指派，R || Cmax 强 NP 难）。
  6. 先写标签、查地图，再决定用规则、动态规划、MIP 还是启发式。经典记号覆盖不了的约束（时间窗、共享资源），也要先找“最接近的经典问题”。
