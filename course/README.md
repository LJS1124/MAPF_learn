# 物流调度与运筹优化：系统课程

面向“四向车与提升机联合调度、造纸物流波次”这类场景的运筹学课程，共 8 个部分、33 章。每章由三样东西组成：

- **交互页**：可拖动、可操作的讲解页面，数字全部实时计算；
- **Lab 代码包**：练习 + 参考答案 + pytest 自动判分，判分数据来自暴力枚举，不依赖你的代码，也不依赖求解器；
- **源码**：页面的 HTML/JS 源、构建脚本与对拍测试，都在本目录里。

完整大纲见 [outline.md](outline.md)。**离线阅读版**（单文件网页和 PDF，不需要网络）见 [offline/](offline/)。

## 约定

- 记号沿用第 2 章：`C[i][j]` 是车 `i` 到任务 `j` 的代价（`m` 行车，`n` 列任务，`m ≥ n`）；任务价格 `u[j]`，车价格 `v[i] ≥ 0`；约化成本 `r[i][j] = C[i][j] + v[i] − u[j] ≥ 0`。
- 默认场景：两层立体库，6 辆车（V6 是备用车）、5 个任务，最优总时间 124 s。行驶耗时是教学用的整数近似（主巷道 2 s/格、货道 3 s/格、换向 5 s、提升机 30 s）。
- 每章的页面数据与 Lab 的判分数据同源：页面里出现的数字，都能在 Lab 的测试里找到对应的断言。
