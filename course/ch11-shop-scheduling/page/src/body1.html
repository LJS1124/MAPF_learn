11流水车间与作业车间：作业要走过好几台机器

前两章的作业只在一台机器（或一组相同的机器）上加工一次。实际的作业常常要依次经过好几道工序：托盘入库、上提升机、出库；一个订单要经过几个站点。这一章看两种最基本的多工序模型：所有作业走同样路线的流水车间，和每个作业路线不同的作业车间。前者在两台机器时有漂亮的规则，后者要用析取图来表示，并且从这里开始，建模方式（MIP 还是 CP）会明显影响能解多大的问题。

学完本章，你能

  1. 用递推公式算出流水车间任意顺序的 Cmax，手写 Johnson 规则解 F2 | | Cmax，并说明为什么三台以上没有这样的规则。
  2. 用 NEH 启发式解一般的流水车间，看出它为什么比随便排好，又为什么不保证最优。
  3. 把作业车间的一个调度写成析取图：选定每台机器上的作业顺序，Cmax 就是最长路，出现环就说明顺序不可行。
  4. 为同一个作业车间问题写出大 M 的 MIP 和 CP-SAT 两种模型，并解释为什么规模一大，两者差距悬殊。

11.1流水车间与 Johnson 规则

流水车间（flow shop）里有 m 台机器，每个作业都按同样的次序经过它们：先第 1 台，再第 2 台……记号是 Fm | | Cmax。作业 j 在第 k 台机器上的加工时间是 pjk。入库 → 提升机 → 出库就是一个 F3。

每台机器一次只做一个作业，一个作业同一时刻只在一台机器上。最常见的限制是置换流水车间（permutation flow shop）：所有机器上的作业顺序相同，于是决策只有一个，就是作业的排列。对 Cmax 而言，两台和三台机器时最优调度总可以取成置换的，所以下面只看排列。

给定排列，各作业在各机器上的完工时间由一个递推给出。设 Cjk 是排在第 j 位的作业在机器 k 上的完工时间：

完工时间递推Cjk = max( Cj−1,k, Cj,k−1 ) + pjk要等这台机器上一个作业做完，也要等自己在上一台机器上做完

Cmax 就是最后一个作业在最后一台机器上的完工时间。这个递推是 O(nm) 的，所以评价一个排列很便宜，难的是在 n! 个排列里找最好的。

两台机器：Johnson 规则（1954）。F2 | | Cmax 有一个多项式的最优算法。记作业 j 在两台机器上的时间为 aj、bj：

  1. 把 aj ≤ bj 的作业放进集合 1，把 aj > bj 的放进集合 2。
  2. 集合 1 按 a 从小到大排在前面，集合 2 按 b 从大到小排在后面。

直觉是两头夹：第二台机器要等第一台送来作业才能开工，所以让 a 小的作业先走，第二台机器早早有活干；最后一个作业在第二台机器上做完就结束了，所以让 b 小的作业留到最后，收尾的空转最短。证明用的是交换论证，和上一章一样：对相邻的两个作业 i、j，若 min(ai, bj) ≤ min(aj, bi)，则把 i 排在 j 前面不会更差。这个两两比较的关系是可以传递的，所以能推出整个顺序。

读图

原顺序 J1…J6：Cmax = 35。J2 在第一台机器上要 9，第二台机器在这段时间里几乎全部空着。Johnson 顺序：集合 1 是 J1、J6、J2（a 依次为 1、1、9，并列取下标小的），集合 2 是 J3、J5、J4（b 依次为 5、4、2）。得到 J1 → J6 → J2 → J3 → J5 → J4，Cmax = 31，与枚举 720 种得到的最优一致。最差顺序：41，比最优多 10。

试着把 Johnson 顺序里的两个作业交换。绝大多数交换会让 Cmax 变大或不变，不会变小。这就是最优的含义。

三台机器

F3 | | Cmax 是强 NP 难的（Garey、Johnson、Sethi，1976），所以不能指望像 Johnson 那样的规则。有一个特殊情形可以化简：若第二台机器被“压住”，即 min a ≥ max b 或 min c ≥ max b（a、b、c 是三台机器的时间），那么把每个作业合成 (a+b, b+c) 两台虚拟机器，再用 Johnson 规则就是最优的。一般情形没有这个性质，下一节用启发式。

11.2三台以上：NEH 启发式

机器多了以后，实际中最常用的构造启发式是 NEH（Nawaz、Enscore、Ham，1983）。它的想法很简单：加工时间大的作业更“难安排”，先安排它们；每个作业都放在当前最合适的位置。

  1. 按总加工时间 Σk pjk 从大到小排出插入次序。
  2. 取第一个作业，形成只有一个作业的部分顺序。
  3. 依次取下一个作业，试着把它插进部分顺序的每一个位置（含最前和最后），用完工时间递推算出每个位置的 Cmax，保留最小的（并列取靠前的位置）。

插入第 k 个作业要试 k 个位置，总共 O(n²) 次评价，n = 100 也只需要几毫秒。它在流水车间的文献里几乎是“必比的基线”，很多更复杂的方法（禁忌搜索、迭代贪心）都以 NEH 的解为起点。

读图

总加工时间是 J1 15、J2 18、J3 15、J4 18、J5 13、J6 19，所以插入次序是 J6、J2、J4、J1、J3、J5（并列取下标小的）。部分顺序的 Cmax 依次是 19、26、29、33、38、44。最后 NEH 得到 J5 → J1 → J4 → J3 → J6 → J2，Cmax = 44；原顺序 J1…J6 是 52；枚举 720 种得到的最优是 42。NEH 一共只评价了 1 + 2 + 3 + 4 + 5 + 6 = 21 个候选，把 52 压到 44，与最优差 2。

它不保证最优。第 5 步插入 J3 时五个候选是 41、40、38、38、42，最小值 38 出现两次，规则取靠前的那个。换一个并列规则，后面的结果可能不同，所以 Lab 的练习 2 把并列规则写死，让结果可以复现。
